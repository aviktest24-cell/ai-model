# Contributing

Thanks for helping improve NOVA AI.

- Keep the app build-free and compatible with static hosting.
- Keep API failures visible and truthful; never insert fake AI answers.
- Avoid adding provider branding to the user interface.
- Do not commit personal keys, tokens, or private conversation data.
- Test the page on a desktop and a narrow/mobile viewport.
- Run `node --check` on any JavaScript files you change.

For larger changes, describe the feature and any external service limitations in the pull request.
